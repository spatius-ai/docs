## Before you start

Use an existing LiveKit Agents worker and a room that your client can join. Keep its `LIVEKIT_URL`, `LIVEKIT_API_KEY`, and `LIVEKIT_API_SECRET` configured. Get the Spatius App ID and API Key from [Apps](https://app.spatius.ai/apps) and the Avatar ID from the [Avatar Library](https://app.spatius.ai/avatars/library).

## Install

```bash
pip install livekit-plugins-spatius
```

## Configure

Keep the API Key in the worker. Leave `SPATIUS_REGION` unset for `us-west`, or set it to `ap-northeast` or `cn-beijing`.

```bash title=".env"
SPATIUS_API_KEY=your-api-key
SPATIUS_APP_ID=your-app-id
SPATIUS_AVATAR_ID=your-avatar-id
SPATIUS_REGION=us-west
```

## Add the Avatar session

Create `AvatarSession` before starting the agent session. The avatar publishes into the same LiveKit room.

```python
from livekit.plugins.spatius import AvatarSession

# Add these lines inside your existing LiveKit Agents entrypoint.
avatar = AvatarSession()
await avatar.start(session, room=ctx.room)

# Keep your existing session.start(...) call after avatar.start(...).
```

Your voice agent continues to own STT, LLM, and TTS. The plugin sends the agent's speech audio to Motion Server and publishes the avatar output into the room.
