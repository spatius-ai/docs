## Before you start

Start the Convo AI agent or TEN graph on your backend, then return this runtime configuration to the app:

| Value | Source |
| --- | --- |
| Spatius App ID and Avatar ID | The values used by the agent setup |
| Agora App ID and channel | Your Agora project and agent session |
| Client UID and RTC token | Generated by your backend for this participant |

Use a different Agora UID for the client, conversational agent, and avatar publisher. Never send the Spatius API Key or Agora App Certificate to the app. This path does not use a Spatius Session Token.

## Connect the client

<Tabs>
<Tab title="Web">

Install AvatarKit, the Web RTC Adapter, and Agora's Web SDK:

```bash
pnpm add @spatius/avatarkit @spatius/avatarkit-rtc agora-rtc-sdk-ng
```

Configure the AvatarKit WebAssembly assets for [Vite or Next.js](/sdk-reference/web-sdk/toolchain), then connect:

```typescript
import { AvatarManager, AvatarSDK, AvatarView, DrivingServiceMode } from '@spatius/avatarkit'
import { AgoraProvider, AvatarPlayer } from '@spatius/avatarkit-rtc'

await AvatarSDK.initialize(spatiusAppId, {
  drivingServiceMode: DrivingServiceMode.rtc,
})

const avatar = await AvatarManager.shared.load(avatarId)
const avatarView = new AvatarView(
  avatar,
  document.getElementById('avatar-container')!,
)
const player = new AvatarPlayer(new AgoraProvider(), avatarView, {
  logLevel: 'info',
})

await player.connect({
  appId: agoraAppId,
  channel,
  token: clientToken,
  uid: clientUid,
})

await player.startPublishing()

async function disconnectAvatar() {
  await player.stopPublishing()
  await player.disconnect()
  avatarView.dispose()
}
```

Call the connect flow from a user action so the browser can request microphone permission.

<Tab title="iOS">

Install `AvatarKitRTC` with Swift Package Manager or CocoaPods:

In Xcode, open **File > Add Package Dependencies**, enter `https://github.com/spatius-ai/avatarkit-ios-rtc.git`, and select the latest stable release.

```ruby
pod 'AvatarKitRTC'
```

Initialize AvatarKit in RTC mode, load the Avatar, and connect:

```swift
import AvatarKit
import AvatarKitRTC

AvatarSDK.initialize(
    appID: spatiusAppID,
    configuration: Configuration(drivingServiceMode: .rtc)
)

let avatar = try await AvatarManager.shared.load(id: avatarID)
let avatarView = AvatarView(avatar: avatar)
let player = AvatarPlayer(
    provider: AgoraProvider(),
    avatarView: avatarView,
    options: AvatarPlayerOptions(logLevel: .info)
)

try await player.connect(AgoraConnectionConfig(
    appId: agoraAppID,
    channel: channel,
    token: clientToken,
    uid: clientUID
))

try await player.publishAudio()

func disconnectAvatar() async {
    await player.unpublishAudio()
    await player.disconnect()
}
```

Add `NSMicrophoneUsageDescription` to the app and request microphone permission before calling `publishAudio()`.

The default `connect(_:)` path lets `AgoraProvider` own the engine. If your iOS app already owns an `AgoraRtcEngineKit`, attach the player to it before joining the channel instead. The two paths are mutually exclusive; do not create a second engine only for avatar playback.

```swift
import AgoraRtcKit

let engineConfig = AgoraRtcEngineConfig()
engineConfig.appId = agoraAppID
engineConfig.channelProfile = .liveBroadcasting
let engine = AgoraRtcEngineKit.sharedEngine(with: engineConfig, delegate: yourEngineDelegate)

let player = AvatarPlayer(provider: AgoraProvider(), avatarView: avatarView)

// Attach before joining the channel.
try player.attach(to: engine)

engine.setClientRole(.broadcaster)
let options = AgoraRtcChannelMediaOptions()
options.clientRoleType = .broadcaster
options.autoSubscribeAudio = true
options.autoSubscribeVideo = true
options.publishCameraTrack = false
options.publishMicrophoneTrack = true
engine.joinChannel(byToken: clientToken, channelId: channel, uid: clientUID, mediaOptions: options)

func disconnectAvatar() async {
    await player.detach()
    engine.leaveChannel(nil)
    AgoraRtcEngineKit.destroy()
}
```

<Note>
Your app keeps owning the engine: it creates it, sets the client role, joins and leaves the channel, and destroys it. `detach()` hands it back without leaving the channel. `attach(to:)` does change two engine settings, and `detach()` does not restore them: it enables SEI (`rtc.video.enable_sei`), which the avatar needs, and sets the audio scenario to `.chorus`. If your app needs a different audio scenario, set it after calling `attach(to:)`.
</Note>

<Tab title="Android">

Add the Android RTC package:

```kotlin
implementation("ai.spatius:avatarkit-rtc:<latest-version>")
```

Use the latest stable release from [Maven Central](https://central.sonatype.com/artifact/ai.spatius/avatarkit-rtc).

Initialize AvatarKit in RTC mode, load the Avatar, then connect the player:

```kotlin
import ai.spatius.avatarkit.AvatarSDK
import ai.spatius.avatarkit.AvatarView
import ai.spatius.avatarkit.Configuration
import ai.spatius.avatarkit.DrivingServiceMode
import ai.spatius.avatarkit.assets.AvatarManager
import ai.spatius.avatarkit.rtc.AgoraConnectionConfig
import ai.spatius.avatarkit.rtc.AvatarPlayer
import ai.spatius.avatarkit.rtc.AvatarPlayerOptions
import ai.spatius.avatarkit.rtc.RTCLogLevel
import ai.spatius.avatarkit.rtc.providers.AgoraProvider

AvatarSDK.initialize(
    context = context,
    appId = spatiusAppId,
    configuration = Configuration(
        drivingServiceMode = DrivingServiceMode.RTC,
    ),
)

AvatarManager.initialize(context)
val avatar = AvatarManager.load(avatarId) ?: error("Avatar load failed")
val avatarView = AvatarView(context)
avatarView.init(avatar, lifecycleScope)

val player = AvatarPlayer(
    provider = AgoraProvider(context),
    avatarView = avatarView,
    options = AvatarPlayerOptions(logLevel = RTCLogLevel.INFO),
)

player.connect(
    AgoraConnectionConfig(
        appId = agoraAppId,
        channel = channel,
        token = clientToken,
        uid = clientUid,
    )
)

player.publishAudio()

suspend fun disconnectAvatar() {
    player.unpublishAudio()
    player.disconnect()
}
```

Declare `android.permission.RECORD_AUDIO` and request the runtime permission before calling `publishAudio()`.

The default `connect(...)` path lets `AgoraProvider` own the engine. If your Android app already owns an `RtcEngine`, attach the player to it before joining the channel instead. The two paths are mutually exclusive; do not create a second engine only for avatar playback.

```kotlin
import io.agora.rtc2.ChannelMediaOptions
import io.agora.rtc2.Constants
import io.agora.rtc2.RtcEngine
import io.agora.rtc2.RtcEngineConfig

val engine = RtcEngine.create(RtcEngineConfig().apply {
    mContext = context
    mAppId = agoraAppId
    mEventHandler = yourEngineEventHandler
    mChannelProfile = Constants.CHANNEL_PROFILE_LIVE_BROADCASTING
})

val player = AvatarPlayer(
    provider = AgoraProvider(context),
    avatarView = avatarView,
)

// Attach before joining the channel.
player.attach(engine)

engine.setClientRole(Constants.CLIENT_ROLE_BROADCASTER)
engine.joinChannel(clientToken, channel, clientUid.toInt(), ChannelMediaOptions().apply {
    clientRoleType = Constants.CLIENT_ROLE_BROADCASTER
    autoSubscribeAudio = true
    autoSubscribeVideo = true
    publishCameraTrack = false
    publishMicrophoneTrack = true
})

suspend fun disconnectAvatar() {
    player.detach()
    engine.leaveChannel()
    RtcEngine.destroy()
}
```

<Note>
Your app keeps owning the engine: it creates it, sets the client role, joins and leaves the channel, and destroys it. `detach()` hands it back without leaving the channel. `attach(engine)` does change two engine settings, and `detach()` does not restore them: it enables SEI (`rtc.video.enable_sei`), which the avatar needs, and sets the audio scenario to `AUDIO_SCENARIO_CHORUS`. If your app needs a different audio scenario, set it after calling `attach(engine)`.
</Note>

The packaged `AgoraProvider` coordinates audio and motion data. On the default `connect` path, it also owns the RTC lifecycle. Do not also call Backend Mode feed methods.
