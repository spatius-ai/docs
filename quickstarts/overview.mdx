Quickstarts are the shortest path from credentials to a visible speaking avatar on one platform. Each one runs the Direct Mode SDK against Motion Server with a Session Token.

For voice-agent or backend-controlled demos, see the separate [LiveKit Agents Integration quickstart](/livekit-agents/quickstart) and [Browse all demos](/resources/demo-projects).

## Platform quickstarts

| Platform | Quickstart | What it proves |
| --- | --- | --- |
| **Web** | [Web SDK](/quickstarts/web-sdk) | App ID, Avatar ID, Session Token, Motion Server connection, PCM audio send, and local rendering. |
| **iOS** | [iOS SDK](/quickstarts/ios-sdk) | Native iOS AvatarKit setup with runtime Session Token. |
| **Android** | [Android SDK](/quickstarts/android-sdk) | Native Android AvatarKit setup with runtime Session Token. |
| **Flutter** | [Flutter SDK](/quickstarts/flutter-sdk) | Flutter AvatarKit setup on iOS or Android with runtime Session Token. |
