## Installation

Use the latest standard release from [Maven Central](https://central.sonatype.com/artifact/ai.spatius/avatarkit). Compatibility-suffixed artifacts expose a reduced API and are not a drop-in replacement.

```kotlin title="build.gradle.kts"
dependencies {
    implementation("ai.spatius:avatarkit:<latest-version>")
}
```

<Accordion title="setAudioFormat(sampleRate, opusBitrate, inputAudioFormat, opusUplinkEnabled)">
Changes the audio format of this view without reinitializing the SDK. Only the parameters you pass change; `null` keeps the current value.

```kotlin
fun setAudioFormat(
    sampleRate: Int? = null,
    opusBitrate: Int? = null,
    inputAudioFormat: AudioCodec? = null,
    opusUplinkEnabled: Boolean? = null,
)
```

**Parameters:**
- `sampleRate`: The new sample rate in Hz. Accepted: 8000, 16000, 22050, 24000, 32000, 44100, 48000.
- `opusBitrate`: The new uplink Opus bitrate in bits/sec.
- `inputAudioFormat`: The new codec of the audio you feed into the SDK.
- `opusUplinkEnabled`: Whether the SDK compresses the Direct Mode uplink to Opus.

Any change interrupts the current playback and, in Direct Mode, disconnects. Call `start()` to reconnect; audio you feed after the call is interpreted in the new format. The SDK recreates the `AudioTrack` for the next conversation automatically; no audio-side work is needed. Passing values identical to the current format does nothing.

- Switching `inputAudioFormat` to `AudioCodec.OPUS` sets the sample rate to 48000. Switching back to `AudioCodec.PCM` keeps the current rate unless you pass `sampleRate` in the same call.
- With PCM input at a rate the Opus uplink does not support (anything other than 8000, 16000, 24000, or 48000), the SDK sends raw PCM. Changing back to a supported rate restores the Opus uplink you requested.
- An unsupported `sampleRate`, or a `sampleRate` passed with Opus input, logs an error and leaves the format unchanged. It is not reported through `onError`.
</Accordion>

#### Render over an Avatar Background

Download the optional 16:9 background from Spatius Studio and add it as a drawable resource. In Compose, place the background `Image` and `AvatarView` in the same `Box`. `AvatarView` renders on a transparent surface by default, so the background shows through.

```kotlin
@Composable
fun AvatarStage(
    avatar: Avatar,
    scope: CoroutineScope,
) {
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .aspectRatio(16f / 9f)
            .clipToBounds(),
    ) {
        Image(
            painter = painterResource(R.drawable.avatar_background),
            contentDescription = null,
            contentScale = ContentScale.Crop,
            modifier = Modifier.fillMaxSize(),
        )

        AndroidView(
            factory = { context ->
                AvatarView(context).also { avatarView ->
                    avatarView.init(avatar, scope)
                }
            },
            modifier = Modifier.fillMaxSize(),
        )
    }
}
```

For square or portrait display windows, center this 16:9 stage inside a clipped outer container. See [Avatar Background](/concepts/avatar-background) for the shared cropping rules.

### Configuration

SDK configuration class.

```kotlin
data class Configuration
```

##### Initializers

<Accordion title="Configuration(region, drivingServiceMode, logLevel, renderQuality, extraParams)">
Creates a new configuration with the specified parameters.

```kotlin
data class Configuration(
    val region: String = "auto",
    val drivingServiceMode: DrivingServiceMode = DrivingServiceMode.DIRECT,
    val logLevel: LogLevel = LogLevel.OFF,
    val renderQuality: RenderQuality = RenderQuality.ULTRA,
    val extraParams: Map<String, String> = emptyMap()
)
```

**Parameters:**
- `region`: The region to connect to. Defaults to `"auto"`: the SDK selects the closest serving region at initialization and reuses the cached choice on later launches. Pass `"us-west"`, `"ap-northeast"`, or `"cn-beijing"` to force that region. If automatic selection cannot be reached, the SDK falls back to a default region and continues initializing.
- `drivingServiceMode`: The driving service mode
- `logLevel`: The log level
- `renderQuality`: Render quality tier
- `extraParams`: Application-defined metadata sent unchanged in the session handshake when the SDK connects to Motion Server. Defaults to empty. The map is copied when `AvatarSDK.initialize()` is called, so later changes to the map you passed have no effect. Not used when requesting or setting a session token.

The audio format is set per view; see [`AvatarView.init`](#avatarview) and [AudioFormat](#audioformat).
</Accordion>

### AudioFormat

Audio format of an `AvatarView`. Pass it to `AvatarView.init(...)` and change it later with `controller.setAudioFormat()`.

```kotlin
class AudioFormat
```

##### Initializers

<Accordion title="AudioFormat(sampleRate:opusBitrate:inputAudioFormat:opusUplinkEnabled:)">
Creates a new audio format.

```kotlin
class AudioFormat(
    sampleRate: Int,
    val opusBitrate: Int = 48000,
    val inputAudioFormat: AudioCodec = AudioCodec.PCM,
    val opusUplinkEnabled: Boolean = true,
)
```

**Parameters:**
- `sampleRate`: The audio sample rate in Hz. Supported sample rates are: 8000, 16000, 22050, 24000, 32000, 44100, 48000. Not used when `inputAudioFormat` is `AudioCodec.OPUS`: Opus always decodes at 48 kHz, so the view runs at 48000.
- `inputAudioFormat`: The codec of the audio you feed into the SDK via `send` or `yieldAudioData`. `AudioCodec.PCM` (default) for raw PCM16, `AudioCodec.OPUS` for Opus. Applies to all audio fed to the view until you change it with `controller.setAudioFormat()`; audio that does not match is reported as `AvatarError.InvalidAudioInput`.
- `opusUplinkEnabled`: Whether the SDK compresses the direct mode uplink to Opus. On by default, which reduces the upload to roughly an eighth at the cost of encoding on the client. Set `false` to keep a raw PCM uplink. Not used in `BACKEND` mode, which has no uplink, or with Opus input, which is already compressed. With PCM input, `sampleRate` must be 8000, 16000, 24000, or 48000; on any other rate the SDK logs a warning and sends raw PCM instead of failing to initialize.
- `opusBitrate`: Target bitrate in bits/sec for the uplink the SDK encodes. Defaults to 48000. Higher means better quality and a larger upload.
</Accordion>

### DrivingServiceMode

Driving service modes for AvatarKit.

```kotlin
enum class DrivingServiceMode
```

| Case | Description |
|------|-------------|
| `DIRECT` | The SDK handles the Motion Server connection directly. |
| `BACKEND` | The host application provides response audio and motion data. |
| `RTC` | The avatar is driven through the companion RTC SDK, `ai.spatius:avatarkit-rtc`. It does not connect to a channel by itself; see [Agora Convo AI Client](/agora-convoai/client). |

### AudioCodec

Codec of the audio the host feeds into the SDK.

```kotlin
enum class AudioCodec
```

| Case | Description |
|------|-------------|
| `PCM` | Raw PCM16, mono. The default. |
| `OPUS` | Opus. Decoded to PCM locally; in Direct Mode, forwarded upstream unchanged. |
