## Installation

<Tabs>
<Tab title="Swift Package Manager">

In Xcode, open **File > Add Package Dependencies**, enter `https://github.com/spatius-ai/avatarkit-ios-release.git`, and select the latest stable release.

</Tab>
<Tab title="CocoaPods">

AvatarKit is published to its own [CocoaPods spec repository](https://github.com/spatius-ai/avatarkit-specs), because the public CocoaPods trunk stops accepting new versions. Add it as a source at the top of your `Podfile`, and keep the CocoaPods CDN for third-party dependencies:

```ruby title="Podfile"
source 'https://github.com/spatius-ai/avatarkit-specs.git'
source 'https://cdn.cocoapods.org/'

pod 'SpatiusAvatarKit'
```

Then run `pod install --repo-update`.

The pod is named `SpatiusAvatarKit`, but the module name is unchanged: import it as `import AvatarKit`.

</Tab>
<Tab title="Manual">

Download the latest [AvatarKit.xcframework](https://github.com/spatius-ai/avatarkit-ios-release/releases/latest) from the releases page, unzip, and drag it into your Xcode project. Set **Embed & Sign** in your target's **Frameworks, Libraries, and Embedded Content**.

</Tab>
</Tabs>

<Accordion title="setRenderQuality(_:)">
Update the global rendering quality tier. The change takes effect on the next rendered frame across all active `AvatarView` instances.

```swift
static func setRenderQuality(_ quality: RenderQuality)
```

- Call it after `initialize(appID:configuration:)`. A call made before that is ignored and an error is logged; pass the initial tier as `Configuration.renderQuality` instead.
- Calling `setRenderQuality(_:)` turns automatic adjustment (`setAutoRenderQuality(enabled:options:)`) off.
</Accordion>

<Accordion title="setAutoRenderQuality(enabled:options:)">
Let the SDK lower the render quality tier when the GPU cannot keep up. Off by default.

```swift
static func setAutoRenderQuality(
    enabled: Bool,
    options: AutoRenderQualityOptions = AutoRenderQualityOptions()
)
```

```swift
AvatarSDK.onRenderQualityChanged = { quality, reason in
    print("Render quality: \(quality), \(reason)")
}
AvatarSDK.setAutoRenderQuality(enabled: true, options: AutoRenderQualityOptions(maxQuality: .high))
```

- The SDK judges the load only from frames rendered while the Avatar is idle; speaking frames depend on the network and are not used. It lowers the tier one step at a time when the GPU render time exceeds `loadThreshold` of the 40 ms frame budget (25 fps).
- Besides the three tiers, the SDK uses one intermediate step between each pair of tiers. The reported tier is the highest tier not above the current step. `onRenderQualityChanged` is called only when that tier changes, with `.autoDowngrade` or `.autoUpgrade`.
- Quality stays between `minQuality` and `maxQuality`; with `allowUpgrade` it is raised again when the load drops. A current tier outside that range is moved into it as soon as automatic adjustment is turned on.
- Call it after `initialize(appID:configuration:)`. A call made before that, a `loadThreshold` outside 0.6–1.0, or a `minQuality` above `maxQuality` is ignored and an error is logged.
- `setAutoRenderQuality(enabled: false)` and `setRenderQuality(_:)` both turn automatic adjustment off and keep the current tier.

See [AutoRenderQualityOptions](#autorenderqualityoptions) for the options.
</Accordion>

<Accordion title="setRenderResolutionConfig(enabled:config:)">
Keep the drawable height of every `AvatarView`, in physical pixels, within `[minHeight, maxHeight]`. Aspect ratio and the view's layout size are unchanged; Core Animation scales the drawable to fit. The quality tier's render scale still applies on top. Off by default.

```swift
static func setRenderResolutionConfig(
    enabled: Bool,
    config: RenderResolutionConfig = RenderResolutionConfig()
)
```

```swift
AvatarSDK.setRenderResolutionConfig(
    enabled: true,
    config: RenderResolutionConfig(minHeight: 1080, maxHeight: 1440)
)
```

- `minHeight`: a view shorter than this renders at `minHeight` and is scaled down. Small views render noticeably sharper, at extra GPU cost.
- `maxHeight`: a view taller than this renders at `maxHeight` and is scaled up, which saves GPU work on high-density screens.
- A bound left `nil` is not applied.
- A non-positive bound, or a `minHeight` above `maxHeight`, makes the call ignored: an error is logged and the current setting is kept.
- Takes effect on the next layout pass of every active view. Read the current setting from `renderResolutionEnabled` and `renderResolutionConfig`.
</Accordion>

<Accordion title="setRenderResolutionCap(enabled:maxHeight:) (deprecated)">
<Warning>
**Deprecated.** Use `setRenderResolutionConfig(enabled:config:)` with `RenderResolutionConfig(maxHeight:)` instead. `setRenderResolutionCap(enabled:maxHeight:)` and the `renderResolutionCapEnabled` and `renderResolutionMaxHeight` properties keep working and will be removed in the next GA release.
</Warning>

Cap the drawable height while preserving the view's layout size. A non-positive `maxHeight` makes the call ignored: an error is logged and the current setting is kept.

```swift
static func setRenderResolutionCap(enabled: Bool, maxHeight: Int = 1440)
```

```swift
// Replacement
AvatarSDK.setRenderResolutionConfig(enabled: true, config: RenderResolutionConfig(maxHeight: 1080))
```
</Accordion>

<Accordion title="setAudioFormat(sampleRate:inputAudioFormat:opusBitrate:opusUplinkEnabled:)">
Changes the audio format of this view without tearing down the SDK. Only the parameters you pass change; `nil` keeps the current value.

```swift
func setAudioFormat(
    sampleRate: Int? = nil,
    inputAudioFormat: AudioCodec? = nil,
    opusBitrate: Int? = nil,
    opusUplinkEnabled: Bool? = nil
)
```

**Parameters:**
- `sampleRate`: The new sample rate in Hz. Accepted: 8000, 16000, 22050, 24000, 32000, 44100, 48000. Not accepted with Opus input.
- `inputAudioFormat`: The new input codec. Switching to `.opus` pins the sample rate at 48000. Switching back to `.pcm` keeps the current rate unless `sampleRate` is passed in the same call.
- `opusBitrate`: The new target bitrate for the SDK-encoded uplink.
- `opusUplinkEnabled`: Whether the Direct Mode uplink is Opus-compressed.

Any change interrupts the current playback and, in Direct Mode, disconnects from Motion Server. Call `start()` to reconnect; audio sent after the call is interpreted in the new format. The audio engine reconnects automatically, so no audio-side work is needed. An unsupported sample rate, or a `sampleRate` passed with Opus input, logs an error and leaves the format unchanged. Passing values identical to the current format does nothing.
</Accordion>

#### Render over an Avatar Background

Download the optional 16:9 background from Spatius Studio and add it to the Asset Catalog. Place the image and `AvatarView` in the same `ZStack`, with the image first. `AvatarView` is transparent by default, so the background shows through.

```swift
struct AvatarLayer: UIViewRepresentable {
    let avatar: Avatar

    func makeUIView(context: Context) -> AvatarView {
        AvatarView(avatar: avatar)
    }

    func updateUIView(_ avatarView: AvatarView, context: Context) {}
}

struct AvatarStage: View {
    let avatar: Avatar

    var body: some View {
        ZStack {
            Image("AvatarBackground")
                .resizable()
                .aspectRatio(contentMode: .fill)

            AvatarLayer(avatar: avatar)
        }
        .aspectRatio(16 / 9, contentMode: .fit)
        .clipped()
    }
}
```

For square or portrait display windows, center this 16:9 stage inside a clipped outer view. See [Avatar Background](/concepts/avatar-background) for the shared cropping rules.

### AudioFormat

Audio format configuration for an `AvatarView`. Pass it to `AvatarView(avatar:audioFormat:)`; change it later with `controller.setAudioFormat(sampleRate:inputAudioFormat:opusBitrate:opusUplinkEnabled:)`.

```swift
struct AudioFormat
```

##### Initializers

<Accordion title="init(sampleRate:inputAudioFormat:opusBitrate:opusUplinkEnabled:)">
Creates a new audio format.

```swift
init(
    sampleRate: Int = 16000,
    inputAudioFormat: AudioCodec = .pcm,
    opusBitrate: Int = 48000,
    opusUplinkEnabled: Bool = true
)
```

**Parameters:**
- `sampleRate`: The audio sample rate in Hz. Defaults to 16000. Supported: 8000, 16000, 22050, 24000, 32000, 44100, 48000. Not used when `inputAudioFormat` is `.opus`: Opus always decodes at 48 kHz, so the session runs at 48000.
- `inputAudioFormat`: The codec of the audio you feed into the SDK via `send` or `yieldAudioData`. `.pcm` (default) for raw PCM16, `.opus` for Opus. Applies until changed with `controller.setAudioFormat(sampleRate:inputAudioFormat:opusBitrate:opusUplinkEnabled:)`; audio that does not match is reported as `AvatarError.invalidAudioInput`.
- `opusBitrate`: Target bitrate in bits/sec for the uplink the SDK encodes. Defaults to 48000. Higher means better quality and a larger upload.
- `opusUplinkEnabled`: Whether the SDK compresses the direct mode uplink to Opus. On by default, which reduces the upload to roughly an eighth at the cost of encoding on the client. Set `false` to keep a raw PCM uplink. Not used in `.backend` mode, which has no uplink, or with Opus input, which is already compressed. With PCM input, `sampleRate` must be 8000, 16000, 24000, or 48000; on any other rate the SDK logs a warning and sends raw PCM instead of failing.
</Accordion>

| Instance Property | Type | Description |
|----------|------|-------------|
| `sampleRate` | `Int` | The audio sample rate in Hz. Reports 48000 when `inputAudioFormat` is `.opus`. |
| `channelCount` | `Int` | The number of audio channels. Fixed to 1 for mono. |
| `inputAudioFormat` | `AudioCodec` | The codec the host feeds into the SDK. |
| `opusBitrate` | `Int` | Target bitrate for the SDK-encoded uplink. |
| `opusUplinkEnabled` | `Bool` | Whether the direct-mode uplink is Opus-compressed. |

Avatar errors for AvatarKit.

```swift
enum AvatarError: LocalizedError
```

| Case | Description |
|------|-------------|
| `avatarIDUnrecognized` | The avatar ID is not recognized. |
| `avatarAssetMissing` | The avatar asset is missing. |
| `sessionTokenInvalid` | The session token is invalid. |
| `sessionTokenExpired` | The session token has expired. |
| `insufficientBalance` | Insufficient balance. |
| `sessionTimeout` | The session timed out. |
| `concurrentLimitExceeded` | Concurrent connection limit exceeded. |
| `failedToFetchAvatarMetadata` | Failed to fetch avatar metadata. |
| `invalidAvatarMetadata` | The avatar metadata is invalid. |
| `incompatibleAvatarAsset` | The avatar asset format or version is incompatible. |
| `failedToDownloadAvatarAssets` | Failed to download avatar assets. |
| `renderNotSupported` | Rendering is not supported on this device (no Metal device). Deterministic — tell the user rather than retry. |
| `renderInitFailed` | The renderer failed to initialize for another reason. |
| `renderBlankCanvas` | The view reported its first frame, but one second later nothing visible had been drawn (every sampled pixel fully transparent). Delivered through `AvatarController.onError`, at most once per view. An Avatar moved entirely out of the view or scaled to nothing by `avatarTransform` is reported the same way. |
| `invalidAnimationData` | The animation data is invalid. |
| `invalidAudioInput` | The audio does not match `controller.audioFormat.inputAudioFormat`. |
| `serverError` | The driving service returned an error. |

| Instance Property | Type | Description |
|----------|------|-------------|
| `errorDescription` | `String?` | A localized description of the error. |
