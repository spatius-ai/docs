## Available regions

Spatius currently operates in a single region: **`us-west`**. Additional regions may be added in future releases.

## Endpoint URLs

You normally do not need to set these explicitly — leaving `SPATIUS_REGION=us-west` (the default) is enough for SDKs and `livekit-plugins-spatius` to compose the right hosts.

| Service | URL |
| --- | --- |
| Console API | `https://console.us-west.spatius.ai/v1/console` |
| Motion Server ingress (v2) | `wss://api.us-west.spatius.ai/v2/driveningress` |

The advanced override environment variables `SPATIUS_CONSOLE_ENDPOINT` and `SPATIUS_INGRESS_ENDPOINT` exist for staging or proxy setups. Leave them unset for normal use.

## Credential portability

The following identifiers are **not region-specific**:

- **App ID**
- **API Key**
- **Avatar ID**
- **Session Token** (generated by the Console API)

When additional regions become available, you will be able to switch regions without rotating credentials or recreating apps and avatars.
